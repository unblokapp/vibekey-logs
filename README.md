# vibekey-logs

Private repository for **redacted** VibeKey diagnostic logs shared from the app.

## How to submit a log

1. In VibeKey: **Settings → About → Save log → Share redacted log**
2. Choose **GitHub** (or email/Drive) from the share sheet
3. Open a [new issue](../../issues/new/choose) and attach the `.txt` file

The app strips typed text, passwords, usernames, and financial data before sharing. **Do not attach an unredacted Save file** — use Share, not Save, when sending logs here.

## For maintainers

- Issues should include steps to reproduce and expected vs actual behavior
- Log filenames look like `VibeKey_log_YYYY-MM-DD_HH-mm-ss_redacted.txt`
- Each file header includes app version, device model, and redaction version

## Privacy

This repo is **private**. Access is limited to the VibeKey team. Do not make this repository public.
